# 🧠 Problem-Solving Method

For every problem:

1. Understand the problem.
2. Think of the brute-force solution.
3. Analyze Time & Space Complexity.
4. Identify the underlying pattern.
5. Try to solve it independently.
6. Implement the solution.
7. Understand **why** it works.
8. Record the important pattern.

> **Don't memorize solutions. Learn the pattern behind them.**
